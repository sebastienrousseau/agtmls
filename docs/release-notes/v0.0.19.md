# AgtMLS v0.0.19

## Highlights ⭐️

* **Measure whether a skill helps**: `scripts/run-uplift-evals.py` runs the same task in Claude Code and Codex with and without a skill, isolated from your own skills and settings, and grades both answers against flaws planted in a fixture. The first runs are recorded in `docs/evidence/`.
* **Skills must earn their tokens**: a skill counts as hardened only if it helps on two agents, each time using at most 1.5 times the tokens of the task without it, unless it gains 20 points or more. No skill meets that bar yet.
* **hardening-agent-config retired**: across two test cases, Claude Code and Codex already found almost every flaw without it, while it cost 1.2 to 1.8 times the tokens. Installed copies keep working and uninstall normally.
* **Generators clean up after a removed skill**: `generate-skill-manifests.py --write` now removes a removed skill's attestations instead of leaving files its own check refuses.
