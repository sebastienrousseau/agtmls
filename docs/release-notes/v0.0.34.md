# AgtMLS v0.0.34

## Highlights ⭐️

* **Foreign audits read the agent configuration**: hook wiring, settings,
  plugin and MCP manifests, instruction files and install snippets are
  audited beside the skills, and a repository with no skills directory is
  audited instead of refused.
* **A hook and MCP inventory in every foreign report**: each command hook
  with its event, matcher or `UNGATED`, hosts and writes outside the repo,
  and each MCP server with its command or URL, in text, JSON and SARIF.
* **Twelve new rules, 52 in all**: ungated every-turn hooks, writes into
  user-level agent settings, plain-HTTP or empty-URL MCP servers,
  self-scheduling, scanner-silencing markers, hidden comment instructions,
  pre-approved destructive commands and stale suppressions, among others
  (agtmls-spec `48f88e3`).
* **Checked against the real thing**: a weekly acceptance run audits the
  eight repositories the rules came from at pinned commits, and a skill
  with no policy is now `unknown`, not `false`, unless it asks for a
  capability.
