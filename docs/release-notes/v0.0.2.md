# AgtMLS v0.0.2

## Highlights ⭐️

* **Guarded releases**: A release workflow that runs only on tag events, with a dry run and a check of the built assets before anything is published.
* **Patch-line version policy**: Versions must increase by exactly 0.0.1 on the 0.0.x line, and the bump tooling enforces it.
