# AgtMLS v0.0.17

## Highlights ⭐️

* **Multi-agent installs keep their own records**: each lockfile entry now names the agents it was installed for, so installing a second agent no longer makes `verify` report the first agent's skills missing, and uninstalling one agent removes only its own copies.
* **Malformed input is reported, not crashed on**: `audit --foreign` skips a marketplace or plugin manifest that is not a JSON object, advisory checks handle any feed or lockfile shape, and every repository validator now names a broken file instead of stopping with a traceback.
* **Three trust skills, as drafts**: `vetting-a-skill-before-install`, `authoring-portable-skills` and `hardening-agent-config` cover vetting a third-party skill before installing it, writing skills that load in every agent, and locking down agent approvals, hooks and MCP servers.
* **A complexity gate**: every function in `scripts/`, `src/` and `fuzz/` is held to cyclomatic 10, cognitive 15, Halstead difficulty 30 and 60 lines, against a baseline that may only shrink; this release brings it from 66 functions over a ceiling to 37.
