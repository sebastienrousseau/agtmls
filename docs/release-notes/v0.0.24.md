# AgtMLS v0.0.24

## Highlights ⭐️

* **Context optimizer engine**: Eliminates conversational boilerplate, measures instruction density, and enforces deterministic prefix caching to optimize token efficiency and prompt cache hit rates.
* **Repomix context packing**: Bundles root project instructions and skill files into token-bounded XML context packs formatted for LLM agents.
* **Automated context density gate**: Integrates validate-context-density.py as check 73 in the validation gate and CI pipeline.
* **Expanded CLI command surface**: Exposes agtmls optimize and agtmls pack subcommands with updated shell completions for Bash, Zsh, and Fish.
