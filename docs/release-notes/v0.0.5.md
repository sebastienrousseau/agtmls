# AgtMLS v0.0.5

## Highlights ⭐️

* **Four more general skills**: `brainstorming`, `giving-code-review`, `refactoring-safely` and `incident-response`.
* **Subagents and commands**: Two subagents, `skill-author` and `registry-auditor`, and three commands, `agtmls-new-skill`, `agtmls-audit` and `agtmls-release`.
* **Correct version bumps**: `bump-version.py` now updates the marketplace catalog and moves accumulated changelog entries into the release.
