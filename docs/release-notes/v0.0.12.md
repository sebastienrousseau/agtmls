# AgtMLS v0.0.12

## Highlights ⭐️

* **Build provenance is checked**: The release audit now requires signed SLSA build provenance for every asset, from this repository's release workflow at the release tag.
* **Verify an asset yourself**: Run `gh attestation verify <file> --repo sebastienrousseau/agtmls` with the release workflow as signer.
* **An accurate security policy**: `SECURITY.md` lists the index signature, the advisory feed and build provenance, and what each proves.
