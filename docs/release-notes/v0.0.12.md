# AgtMLS v0.0.12

## Summary

- **Build provenance is checked, not just produced.** Every release asset
  has carried keyless SLSA build provenance signed through Sigstore; the
  published-release audit now requires it for every asset, from this
  repository's `release.yml` at the release tag on a GitHub-hosted
  runner, and fails naming any asset without it. This is the first
  release audited that way.
- **Check an asset yourself:**
  `gh attestation verify <file> --repo sebastienrousseau/agtmls --signer-workflow sebastienrousseau/agtmls/.github/workflows/release.yml`.
- **An accurate security policy.** `SECURITY.md` no longer says the
  registry index is unsigned; it lists the index signature, the signed
  advisory feed and build provenance as boundaries, and what each proves.
