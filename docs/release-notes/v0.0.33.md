# AgtMLS v0.0.33

## Highlights ⭐️

* **Fewer false alarms on defensive skills**: a skill that quotes "ignore
  previous instructions" as text to distrust is now a MEDIUM finding, not a
  HIGH injection; an unquoted or uncued one stays HIGH.
* **Unpinned MCP servers caught by name**: `"command": "npx", "args": ["-y",
  "pkg@latest"]` is the new AGT-MCP-002 supply-chain finding instead of a
  mislabelled hook (agtmls-spec PR #28).
* **Measured, not assumed**: the security corpus covers both changes, at
  precision and recall 1.000 over 121 cases; the old code scores 0.970 and
  0.990 on it.
