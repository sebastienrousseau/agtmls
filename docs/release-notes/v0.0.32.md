# AgtMLS v0.0.32

## Highlights ⭐️

* **Reproducible builds**: the wheel and sdist are byte-identical wherever
  they are built, from the commit's time as `SOURCE_DATE_EPOCH`; CI compares
  two Linux builds and a macOS build on every change.
* **Supply-chain and docs gates**: every change now runs dependency advisories
  (PyPI and OSV), workflow lint (actionlint, zizmor), markdownlint and link
  checks; zizmor found and fixed a template injection in the signature check.
* **Windows tested**: an install no longer crashes on a cp1252 console, and CI
  runs the installer and the CLI on Windows.
* **Docs that render**: tables, placeholders and anchors that broke on GitHub
  are fixed, the manpage covers every command, and the docs site deploys to
  GitHub Pages.
