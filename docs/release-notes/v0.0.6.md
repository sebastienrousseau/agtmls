# AgtMLS v0.0.6

## Highlights ⭐️

* **Content-addressed skills**: Every skill in `index.json` has an integrity digest. `install` refuses a registry that does not match it and records a lockfile, and `verify` reports skills changed after install.
* **Your prompt file is safe**: `install` no longer overwrites a `CLAUDE.md` or `AGENTS.md` it did not generate, unless you pass `--force`, which backs it up first.
* **Every file in a skill is audited**: The security analyzer reads scripts and configs beside `SKILL.md`, not only Markdown, and catches three evasions that passed before.
* **Dual licence and valid supply-chain files**: AgtMLS is available under Apache-2.0 or MIT, the SPDX SBOM validates, and `doctor`, `status` and `evidence` no longer crash.
