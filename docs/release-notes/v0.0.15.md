# AgtMLS v0.0.15

## Highlights ⭐️

* **Check that your agent loads the skills**: `agtmls verify <agent> --live` asks Claude Code or Codex which skills it actually loads, and fails naming any installed skill it does not list. The Codex check calls no model.
* **Broken user-level skill links**: `doctor` names every link in `~/.claude/skills` or `~/.codex/skills` that no longer resolves. Agents skip these silently, and no lockfile covers them.
* **Release pages in one layout**: every release page now has Highlights, GitHub's generated list of changes, the checksums and a Full Changelog link, and the release audit checks that layout.
