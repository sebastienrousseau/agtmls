# AgtMLS v0.0.8

## Highlights ⭐️

* **The installed CLI works outside a checkout**: `uvx agtmls uninstall`, `doctor` and `--version` now work from the wheel, on your own directory.
* **Thirty analysis rules**: Eleven new rules cover hooks, wildcard tool grants, unpinned runners, permission-bypass flags and more, and matching sees through hidden and fullwidth characters.
* **Audit other people's skills**: `audit --foreign` checks a marketplace, plugin or skills directory at an exact commit, with SARIF output and baselines for CI.
