# AgtMLS v0.0.29

## Highlights ⭐️

* **`pack --max-tokens` means the whole pack**: the budget now counts the XML wrapper, paths and escaping, not just each file's text, so a 140-token budget no longer produces a 294-token pack. `AGENTS.md` is never dropped, and an over-budget pack writes nothing unless you pass `--allow-partial`.
* **Block-scalar descriptions read correctly**: `doctor` and `verify --live` read a `description: >` or `|` as the single character `>` or `|`. They now read it as YAML does, checked against PyYAML on 4,553 random block scalars.
* **Uplift verdicts count failed runs**: a skill arm that finishes fewer runs than the arm without it is `less reliable`, failed attempts' cost is recorded, and token usage is split by kind (input, cache read and write, output, reasoning).
* **`optimize` respects code fences**: blank lines inside fenced code are kept, and fences open and close as CommonMark's do.
