# AgtMLS v0.0.7

## Highlights ⭐️

* **Antigravity is a native agent**: `install`, `verify`, `uninstall` and `doctor` work with Antigravity in `.agents/`.
* **Stable digests and matching exports**: A release changes a skill's digest only when that skill changed, and `export` selects skills the same way `install` does.
* **Releases checked before and after they ship**: A tag cannot be pushed until the preflight proves it is signed and on the right commit, and the audit reads the published release back from GitHub and PyPI.
* **Measured, not claimed**: Nine benchmarked workloads with every raw sample committed, and 100% unit-test coverage of the scripts and library.
