# AgtMLS v0.0.3

## Highlights ⭐️

* **Every provider adapter packaged**: Release bundles now cover every configured provider adapter, not a subset.
* **Optional live provider checks**: Smoke checks can run against live providers when asked, and the version smoke tests no longer depend on the release state.
