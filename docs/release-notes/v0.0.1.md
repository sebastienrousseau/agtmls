# AgtMLS v0.0.1

## Highlights ⭐️

* **First release of the registry**: AgtMLS starts on the 0.0.x line with 20 validated skills, each with routing and behavioral evals.
* **Install and export for many agents**: Skills install for Claude, Codex, Aider and other agents, and export as bundles for OpenAI, Anthropic, Cursor, GitHub Copilot and Continue.
* **Generated, checked artifacts**: The catalog, docs site, MCP resources, SBOM and provenance are generated from the skill tree, and 47 release checks run in CI.
