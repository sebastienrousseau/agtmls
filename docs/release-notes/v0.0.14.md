# AgtMLS v0.0.14

## Summary

- **Six new rules for what hooks and installers do.** `audit` now flags
  hook output that injects context the user never sees (`AGT-HOOK-004`),
  hook code that reads the session transcript (`AGT-HOOK-005`), content
  presented as if a tool had just returned it (`AGT-INJ-007`), a script
  that downloads a file and makes it executable (`AGT-SUPPLY-002`), a
  download checked only against a checksum from the same place
  (`AGT-SUPPLY-003`), and settings or instructions that switch approval
  prompts off (`AGT-PERM-001`). Each was found unflagged in public plugins
  and installers.
- **`doctor` says whether your agent asks before running a tool.** With
  `--target` and `--agent`, it reads Claude Code, Codex and Aider settings
  and warns, naming the file, when the agent runs tools without asking,
  since every skill's safety policy is then advisory. Claude Code's
  classifier-based `auto` mode is reported on its own.
- **Fuzzed parsers.** The parsers for JSON escapes, normalisation, the
  rule set, the advisory feed and `SHA256SUMS` are fuzzed with Atheris in
  CI and replayed on every platform. The first run found the advisory
  feed validator raising on malformed feeds; it now reports them.
- **Tidier uninstall.** `uninstall` removes the skills, commands and agents
  directories it emptied, and the agent directory if that leaves it empty.
- **Hardening.** A CI job no longer checks out a ref read from a file a
  pull request can change, and every code scanning alert is closed.
