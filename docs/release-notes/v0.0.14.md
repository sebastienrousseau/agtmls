# AgtMLS v0.0.14

## Highlights ⭐️

* **Six rules for hooks and installers**: `audit` flags hidden context injection, transcript reads, fake tool output, download-then-execute, same-origin checksums and settings that switch approval prompts off.
* **Approval posture in `doctor`**: `doctor --agent` reads Claude Code, Codex and Aider settings and warns, naming the file, when the agent runs tools without asking.
* **Fuzzed parsers and a tidier uninstall**: The parsers are fuzzed in CI, and `uninstall` removes the directories it emptied.
