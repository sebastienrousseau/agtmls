# AgtMLS v0.0.30

## Highlights ⭐️

* **Installed prompts pass AgtMLS's own check**: the `CLAUDE.md`, `AGENTS.md` or `CONVENTIONS.md` that `install` writes failed `agtmls optimize --check`, because the base and language prompts were joined with two blank lines. They are now joined with one.
* **`optimize --check` says why it fails**: a run of blank lines is named (`N run(s) of blank lines; --write collapses them`). When that was the only problem, it printed `FAIL: <file>` and nothing else.
* **v0.0.29's checksums recorded**: its release notes list the published SHA256SUMS.
