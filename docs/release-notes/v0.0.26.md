# AgtMLS v0.0.26

## Highlights ⭐️

* **Prompt-cache discipline for every agent**: The global system prompt gains a section on keeping the cached prefix intact: pick the model and effort at session start, rewind instead of compacting mid-task, leave the tool set alone mid-task, and keep always-loaded text stable.
* **Skill authors warned about the `model` field**: `authoring-portable-skills` now says to leave a skill's `model` field out unless it is needed, because naming another model makes that turn re-read the whole conversation without cache hits in Claude Code.
* **Sourced from the documentation**: Every rule follows Anthropic's prompt-caching page; a common claim that adding an MCP server always breaks the cache is narrowed to the case the docs describe, tools loaded upfront rather than through tool search.
