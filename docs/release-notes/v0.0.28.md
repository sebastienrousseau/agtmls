# AgtMLS v0.0.28

## Highlights ⭐️

* **A repository can no longer steer uninstall outside its skills directory**: the lockfile lives in the target repo, and an entry pointing at `../../<dir>` with that directory's digest used to be deleted by `uninstall`. Any `name` or `path` that is not a single directory name now makes the lockfile unreadable (exit 3), as agtmls-spec 0.0.3 and agtmls-core 0.0.4 also require.
* **Install checks what it trusts**: when `index.json.sig` is present, `install` verifies it before copying and refuses a bad signature (exit 5), and `--copy` now carries only the files a skill's digest covers.
* **`install --profile` installs the profile**: `--profile minimal` installed all 15 general skills; it now installs the one it lists, as `export` does, so every session loads 14 fewer skill descriptions.
* **Context tooling that does not rewrite instructions**: one token estimate everywhere; `pack` escapes its XML, finds pack skills and fails when files do not fit `--max-tokens`; `optimize` reports filler and timestamps by line instead of deleting them.
