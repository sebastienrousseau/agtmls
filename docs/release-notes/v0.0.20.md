# AgtMLS v0.0.20

## Highlights ⭐️

* **Signed skill attestations**: every skill's attestations now ship in the wheel, signed by the release key, and `scripts/sign-attestations.py --verify` checks them offline. A skill measured by an uplift run also gets an efficacy attestation, bound to the exact bytes that were measured.
* **First hardened skill on evidence**: vetting-a-skill-before-install helps on both agents within the token ceiling (Claude Code +20 points at 1.31 times the tokens, Codex +8 at 1.17 times), and costs less than before: its earlier version used 1.65 and 1.54 times.
* **Audits that answer the first questions**: `audit --foreign` states whether the source is a pinned git commit and lists every file it did not audit, so you can read them all at once.
* **What an install loads every session**: `doctor` reports the skill descriptions and prompt file an install adds to every session, and `verify --live` names any description Codex shows shortened.
