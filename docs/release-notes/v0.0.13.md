# AgtMLS v0.0.13

## Highlights ⭐️

* **Foreign audits read the whole repository**: `audit --foreign` now audits every `SKILL.md`; before, it could stop at the first layout it found and miss most skills.
* **Every foreign audit states its coverage**: The report names what it read and skipped, audits identical copies once, and flags copies that disagree.
* **Offline provenance**: Each release attaches its Sigstore bundle, so an asset can be verified without network access.
* **A harder build**: The release workflow is read-only except for the job that publishes, and every CI install is pinned by hash.
