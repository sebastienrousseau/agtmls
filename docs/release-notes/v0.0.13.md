# AgtMLS v0.0.13

## Summary

- **Foreign audits read the whole repository.** `audit --foreign` used to
  stop at the first skill layout it recognised, so most of a repository
  could go unscanned and still read as clean: 1 of 24 skills in one sampled
  repository, 1 of 13 in another. It now audits every `SKILL.md`, including
  per-harness copies and embedded asset trees, without following symlinks
  or entering dependency directories.
- **Every foreign audit says what it covered.** Identical copies are audited
  once and named; copies that disagree are flagged; the report ends with the
  skills and files read, the auditable files outside any skill with agent
  configurations such as `hooks.json` named, and the directories skipped.
  `--format json` carries the same statement under `coverage`.
- **Releases carry their provenance bundle.** Each release now attaches its
  Sigstore bundle as `agtmls-<version>.intoto.jsonl`, listed in
  `SHA256SUMS`, so an asset can be verified offline with
  `gh attestation verify <file> --bundle agtmls-<version>.intoto.jsonl`.
- **A harder build.** The release workflow is read-only except for the one
  job that publishes, every CI package install is pinned by hash, and the
  OpenSSF Scorecard result is published, so the README badge shows it.
