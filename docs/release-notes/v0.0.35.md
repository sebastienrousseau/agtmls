# AgtMLS v0.0.35

## Highlights ⭐️

* **In lockstep with the AgtMLS family**: agtmls, agtmls-spec,
  agtmls-core, agtmls-wasm, agtmls-mcp, agtmls-lsp, agtmls-action and
  agtmls-scorecard now release together, all at 0.0.35.
* **Workflow rules, 57 in all**: `audit --foreign` reads
  `.github/workflows/` and flags agent actions on mutable refs, secrets
  handed to them, `pull_request_target` checking out the pull request
  head, agents open to any user, and write or OIDC tokens on those
  triggers (AGT-CI-001 to 005).
* **Branches that change agent configuration**: `audit
  --changed-agent-config <base>` lists the hooks, settings, MCP manifests
  and instruction files a branch changes, audits each, and exits 1 when
  any changed.
* **Pinned install commands, and `audit --all` back to speed**: the
  README installs this exact release, and the 0.0.34 slowdown is gone
  (678 ms to 446 ms on this registry).
