# AgtMLS v0.0.31

## Highlights ⭐️

* **Every file says Apache-2.0 OR MIT**: 126 headers, all 33 skills, the plugin manifests and `index.json` said `MIT` alone. The expression is now read from `pyproject.toml`, and a new gate check fails on any label that disagrees.
* **Install never deletes your own skill**: `install --copy` removed a real directory sitting where a skill goes, and a linking install nested its link inside it. Both now refuse before writing anything.
* **Safer installs elsewhere too**: `install` refuses the home directory as a target, `provider-install` backs up a hand-written `AGENTS.md` before replacing it, and the CLI prints the reason a command stopped.
