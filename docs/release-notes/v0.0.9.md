# AgtMLS v0.0.9

## Highlights ⭐️

* **Never built, so nothing to install**: The `v0.0.9` tag was pushed, but its source distribution lacked `ALLOWED_SIGNERS` and `hatch_build.py`, so the release build failed before anything reached GitHub Releases or PyPI. Install v0.0.10 or later.
* **Its changes ship in v0.0.10**: The first signed index, revocation through a signed advisory feed, per-skill attestations, fewer steganography false positives, injection rules that read JSON, YAML and TOML, and the `AGT-HOOK-003` and `AGT-POLICY-006` rules were all first published in [v0.0.10](https://github.com/sebastienrousseau/agtmls/releases/tag/v0.0.10).

## Checksums

None: the build failed before it produced any assets, so this tag has no artifacts to checksum.
