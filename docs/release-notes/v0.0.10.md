# AgtMLS v0.0.10

## Highlights ⭐️

* **The first signed release**: `index.json` is signed in a protected release environment, and `agtmls verify --signatures` checks it offline against the key the wheel ships.
* **Revocation**: `verify` reads a signed advisory feed and exits 6, naming the advisory, when an installed skill has been revoked.
* **Per-skill attestations**: Every skill ships a manifest of its exact files and hashes, and a statement of the capabilities it declares and grants.
* **Carries v0.0.9**: The v0.0.9 tag was never published because its source distribution was incomplete; this release includes all of its changes.
