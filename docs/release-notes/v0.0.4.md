# AgtMLS v0.0.4

## Highlights ⭐️

* **Install from PyPI**: `uvx agtmls` and `pipx install agtmls` work, with the whole registry in the wheel and no runtime dependencies.
* **Six discipline skills**: `writing-plans`, `test-driven-development`, `systematic-debugging`, `verification-before-completion`, `receiving-code-review` and `handoff` install in every repository.
* **A flat skill tree**: Every skill is `skills/<name>/SKILL.md`, so agents that scan non-recursively, such as Codex, Cursor, Gemini CLI and Antigravity, now see all of them.
* **Plugin manifests and a real test suite**: Manifests for eight runtimes are generated from one source, and 65 unit tests check the validators themselves.
