# AgtMLS v0.0.16

## Highlights ⭐️

* **Skills that work in every agent**: `validate-skills.py` fails a skill that uses Claude Code-only syntax (`` !`command` `` or `${CLAUDE_SKILL_DIR}`), chains references more than one level deep, or has a body over about 5,000 tokens. `audit --foreign` reports the same problems as notes.
* **noyalib is its own plugin**: the 14 noyalib skills moved to `packs/noyalib`, so the default plugin carries only general skills. Install them with `/plugin install agtmls-noyalib@agtmls` or `--bundle noyalib`.
* **Verification sized to the risk**: `verification-before-completion` still refuses to call an unchecked claim done, but asks only for the checking the change's risk calls for, with no retry loops and nothing destructive just to prove a claim.
* **Safer multi-agent installs**: uninstalling one agent no longer deletes the lockfile other agents share, and installing for Aider adds `CONVENTIONS.md` to an existing `read:` list instead of adding a second one.
