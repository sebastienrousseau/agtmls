# AgtMLS v0.0.27

## Highlights ⭐️

* **Baselines for third-party skills**: `audit --foreign` now honours `--baseline` and `--write-baseline`, which it used to accept and ignore. A baseline matches wherever the tree sits, including a `<git-url>@<sha>` clone, so a vetted tree can be gated in CI under `--strict`.
* **A tree's author no longer decides its verdict**: `agtmls-ignore` comments in a foreign tree are listed with their reasons but still count toward the exit code. Only the auditor's own baseline excuses a finding.
* **SARIF for foreign audits**: `audit --foreign --format sarif` writes SARIF 2.1.0 with paths relative to the audited tree, instead of printing the text report.
* **Release pages fixed**: the Checksums section opens with its intro line and a `text` fence, and `release-audit.py` refuses a page without them.
