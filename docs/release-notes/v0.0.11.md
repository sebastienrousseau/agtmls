# AgtMLS v0.0.11

## Highlights ⭐️

* **Two implementations, one verdict**: The spec's signature, attestation and advisory chapters are normative, and both this CLI and agtmls-rs must return identical results on every test vector.
* **Check trust by hand**: `scripts/trust-check.py` gives one signature, advisory or attestation verdict per call, with the same flags and exit codes as agtmls-rs.
* **Windows checkouts and more evasions**: Signature tests pass on Windows, and the security corpus grows to 108 cases at precision and recall 1.0.
