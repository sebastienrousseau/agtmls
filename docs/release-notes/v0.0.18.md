# AgtMLS v0.0.18

## Highlights ⭐️

* **Imported skills pass the gate**: `import-skill.py` no longer writes a `version` into the imported skill's metadata, which the registry's own checks refuse, so an imported draft validates as soon as it lands.
* **Malformed eval cases no longer pass**: prompt and needle lists given as a single string were checked one letter at a time, and a gate manifest or lifecycle of the wrong shape could pass. They now fail, naming what is wrong.
* **Broken files are named, not crashed on**: validators, generators and smoke tests report a malformed or non-UTF-8 file by name instead of stopping with a traceback.
* **Every function within its complexity ceiling**: no function or file is over a ceiling any more, from 66 functions and 2 files when the gate arrived, and the gate keeps it that way.
