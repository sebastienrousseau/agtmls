# Support

Where to get help, report bugs, or propose enhancements for AgtMLS.

## Choosing a channel

| You want to…                             | Go to                                                                                         |
| ---------------------------------------- | --------------------------------------------------------------------------------------------- |
| Understand skills, profiles, or providers | The [README](README.md), [docs site](site/index.html), or [`docs/`](docs/)                    |
| Check local environment and setup health | `python3 scripts/agtmls-doctor.py`                                                            |
| Report a bug or regression               | [Bug report](https://github.com/sebastienrousseau/agtmls/issues/new?labels=bug)               |
| Propose a new skill or feature           | [Feature request](https://github.com/sebastienrousseau/agtmls/issues/new?labels=enhancement)   |
| Ask questions or discuss agent workflows | [Discussions](https://github.com/sebastienrousseau/agtmls/discussions)                         |
| Report a security vulnerability          | **Do not open an issue** — see [SECURITY.md](SECURITY.md)                                     |
| Contribute code or documentation         | [CONTRIBUTING.md](CONTRIBUTING.md) and [DEVELOPMENT.md](DEVELOPMENT.md)                       |
